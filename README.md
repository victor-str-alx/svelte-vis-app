# Svelte + Vis.js + Charts

Aplicație demo cu **Svelte**, **Vite**, **TailwindCSS**, **Vis.js** (graf + arbore) și **Chart.js** (grafic funcție + chart bursă).

## Ce conține

- **Graf rețea** (Vis.js) – noduri și muchii, fizică Barnes-Hut
- **Arbore ierarhic** (Vis.js) – layout hierarchical
- **Grafic funcție** (Chart.js) – f(x) = 2·sin(x) + 1.5·cos(x/2)
- **Chart bursă** (Chart.js) – evoluție preț (exemplu)

## Comenzi

```bash
npm install
npm run dev    # dev server
npm run build  # build production
npm run preview # preview build
```

## Tehnologii

- [Vite](https://vitejs.dev/) – build
- [Svelte](https://svelte.dev/) – UI
- [TailwindCSS](https://tailwindcss.com/) – stiluri
- [vis-network](https://visjs.github.io/vis-network/docs/network/) – graf & arbore
- [Chart.js](https://www.chartjs.org/) – grafice line
